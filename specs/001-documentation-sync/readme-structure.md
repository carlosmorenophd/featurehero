# Permanent README Structure

`README.md` must retain three complementary layers after the temporary IA files
are removed.

## 1. Basic usage and commands

Installation, requirements, `featurehero --help`, command syntax, common options,
examples, and expected output locations.

## 2. Application summary

Project reason, objective, developer audience, supported workflows, data formats,
main transformations, optimization purpose, result analysis, and scope limits.

## 3. Technical reference

CLI contracts, validation rules, data flow, models, metrics, genetic algorithm
behavior, job management, generated artifacts, testing, packaging, release
workflow, and known limitations. This layer must describe only verified behavior.
